  │
  ├──→ [Toggle Switch] ──→ Buck IN+
  │                              │
  │                              └──→ Buck OUT+ ──→ ESP32 VIN
  │
  └──→ TB6612 VM (motor power)

Battery -
  │
  ├──→ Buck IN-
  │     └──→ Buck OUT- ──→ ESP32 GND
  │
  └──→ TB6612 GND

ESP32 3.3V ──→ All sensor VCC
ESP32 GND  ──→ All sensor GND
Critical rules:
• All sensors use 3.3V — NEVER 5V or battery directly!
• TB6612 VM uses battery directly (motors need full power)
• ESP32 uses 5V from buck converter via VIN pin
• Toggle switch cuts ALL power when flipped OFF
• TP4056 charges batteries via USB — disconnect when robot running!
